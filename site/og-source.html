Hookgres

Webhooks that commit with your data.

Signed, retried webhooks in your Postgres transaction.

npm$ npm install hookgres pg
Docshookgres.dev
billing.ts
await client.query("BEGIN");
// …your writes…
await hookgres.send({
  tenantId: "acme",
  eventType: "invoice.paid",
  payload: { id },
}, { client });
await client.query("COMMIT");
