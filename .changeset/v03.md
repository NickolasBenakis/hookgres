Add `cleanup({ olderThan, batchSize })`, which deletes old messages whose deliveries are all finished, in batches, and returns how many it deleted. Add the `retryJitter` option (default 0.1), which spreads each retry wait randomly by up to that fraction so failed deliveries don't all retry at once; set it to 0 for exact waits. Endpoint `eventTypes` now accept wildcards like `invoice.*`, which match every event type under `invoice.` at any depth. A bare `*` is rejected (use `null` for every event), and event types passed to `send()` can't contain `*`. An endpoint saved before 0.3 with a literal entry like `invoice.*` now matches as a wildcard.
